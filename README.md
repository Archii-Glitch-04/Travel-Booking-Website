# **Safar-E-Hind: A Full-Stack Indian Travel Booking Platform**

**Safar-E-Hind** is a full-stack travel booking website designed to offer users a seamless and culturally rich experience while exploring and booking train journeys across India. Built with modern technologies, this application combines an interactive frontend with a robust backend to simulate a real-world travel booking system, enhanced by vibrant visuals, heritage-themed UI, and engaging content such as Indian cuisines and tourist destinations.

---

### **Key Features**

- **Login Authentication** for secure access
- **Search Trains** by source, destination, and date
- **Real-Time Booking** simulation with confirmation popups
- **Train Results** Displayed in a dynamic, styled table
- **“Flavours of India”**: A visually rich section showcasing Indian cuisines
- **Popular Destinations** Grid linking to tourist websites
- **Fully responsive UI** with cultural elements and animated transitions

---

### **Technologies Used**

- **Frontend**: React.js, Vite, CSS3
- **Backend**: Node.js, Express.js
- **Database**: MongoDB (via MongoDB Atlas)
- **Other Tools**: Axios, Mongoose, Git, VS Code, Postman

---

### **Purpose**

This project was developed to understand and apply full-stack development concepts while building a real-life simulation of a travel booking platform. It aims to integrate database operations, API calls, user interactivity, and UI/UX best practices into a single cohesive system.
